# Victrl — 合规与授权说明

> **中文** | [English](Compliance.md)

## 一、本文目的

Victrl 是一台**硬件 AI Agent**：它通过外置 HDMI 采集卡读取被控设备的屏幕，再以模拟的蓝牙/USB 键鼠驱动该设备。本文明确说明：**什么情况下这样做是合法的，什么情况下不是，以及项目维护者对使用者的要求**，以免使用者和项目本身承担不必要的法律风险。

本文是面向工程实践的合规提示，**不构成法律意见**。

---

## 二、Victrl 做了什么、没做什么

| Victrl **会** | Victrl **不会** |
| --- | --- |
| 用外置采集卡读取被控设备的 HDMI/显示输出 | 在被控系统上安装、注入、挂钩或修改**任何东西** |
| 模拟标准蓝牙/USB 键盘与鼠标 | 读取被控设备的文件、内存、磁盘或内部数据通道 |
| 把画面与任务上下文交给多模态模型，并执行模型返回的动作 | 利用漏洞、破解口令、证书或签名 |
| 以**被控设备上当前已登录的账号**身份操作 | 绕过开机口令、登录界面、权限策略或防火墙 |
| 把任务历史、计划、设备画像保存在 **Victrl 主机**上 | 隐藏自身，或关闭被控设备的安全软件 |

由此有两点法律上的要害：

1. **Victrl 不具备“突破”能力。** 它没有任何以规避安全保护措施为目的的代码。按对法释〔2011〕19 号第二条的主流理解，只有 “具有避开或者突破计算机信息系统安全保护措施、未经授权或者超越授权获取数据或实施控制的功能” 的程序、工具，才属于 “专门用于侵入、非法控制计算机信息系统的程序、工具”。Victrl 不具备该功能。
2. **Victrl 本身不授予任何授权。** 它就是一套键盘和鼠标。在一台电脑上用键盘是否合法，只取决于操作者与这台电脑的关系，与这个外设无关。

因此，决定性的问题始终是：**这是谁的设备，你有没有被允许去操作它？**

## 三、法律框架（中国大陆）

### 3.1 《刑法》第二百八十五条

| 条款 | 罪名 | 与 Victrl 的关系 |
| --- | --- | --- |
| 285 条 1 款 | 非法侵入**国家事务、国防建设、尖端科学技术领域**的计算机信息系统 | 把 Victrl 用于涉密、军工类系统最容易触发。本款**只要求 “侵入” 行为本身**，不问后果、不论金额。 |
| 285 条 2 款 | **非法获取计算机信息系统数据、非法控制计算机信息系统** | 真正的风险所在。“采用其他技术手段” 是开放的构成要件，完全可以涵盖硬件键鼠/视觉自动化；**手段在目标之外，并不等于不落入本款**——法条表述是 “侵入……**或者采用其他技术手段**”，并不要求 “突破”。 |
| 285 条 3 款 | 提供侵入、非法控制计算机信息系统的程序、工具 | 指向作者与分发者，见第五节。 |

### 3.2 入罪标准（“情节严重”）——法释〔2011〕19 号第一条

非法控制或非法获取数据，**满足以下任一项**即达到 “情节严重”：

- 非法控制计算机信息系统 **20 台以上**；
- 获取支付结算、证券交易、期货交易等网络金融服务身份认证信息 **10 组以上**，或第（一）项以外的身份认证信息（账号、口令、密码、数字证书等）**500 组以上**；
- **违法所得 5000 元以上**，或造成经济损失 **1 万元以上**；
- 其他情节严重的情形。

达到上述标准 **5 倍以上**（100 台 / 2500 组 / 2.5 万元）为 “情节特别严重”，处 **3 年以上 7 年以下**有期徒刑。该条第三款还规定：**明知是他人非法控制的计算机信息系统，而对该系统的控制权加以利用的，依照前两款定罪处罚。**

*实务理解：* 所有者对自己的一台设备使用，与这些门槛相距甚远。真正入罪的案件，驱动力是规模、无授权和牟利。

### 3.3 其他需要注意的条款

- **第286条**——破坏计算机信息系统罪（对数据进行删除、修改、增加，或造成系统不能正常运行）。即使你有权操作这台机器，通过 Victrl 删除或篡改他人的数据也可能落入本条。广州越秀某停车场案中，行为人用远程控制软件删除收费系统数据，即按第286条方向追究刑事责任。
- **《网络安全法》第27条**——不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等活动。即便未达到刑事门槛，本条亦可适用。
- **合同与管理制度**——被控设备的软件许可协议、用人单位的 IT/安全制度，可能独立地禁止无人值守的自动化操作，哪怕设备本身你有权使用。

### 3.4 司法实践如何看待 “不装软件、模拟人操作”

- **最高人民法院指导案例145号**：以植入木马获取服务器控制权限属于第285条第2款 “采用其他技术手段” 非法控制计算机信息系统；同时确认未造成 “功能实质性破坏” 的控制行为，应认定第285条第2款，而非第286条。
- **全国首例 “AI外挂” 案**（江西鹰潭市余江区人民法院，2024年5月6日）：涉案 “盒子程序” **接收计算机USB 端口传输的鼠标数据指令，并对指令进行计算解析，再将计算结果发送至计算机 USB 端口**，从而实现鼠标自动移动和点击——即硬件级 HID 自动化。法院以 “提供侵入、非法控制计算机信息系统的程序、工具罪” 判处被告人有期徒刑三年、缓刑五年。
- **反对观点是真实存在的。** 已有律师公开论证：该 “AI外挂” 程序不具备 “避开或突破安全保护措施” 的功能，实质是自动化操作工具，该判决更多考虑了社会效果。对于 “类人式硬件自动化” 究竟落在何处，各地法院尚未完全统一。

**对 Victrl 的意义：** 技术上的差异是有利的——Victrl 是单向的（画面进、输入出），不装任何东西，不读取目标数据，不突破任何机制，也无法获得比当前登录账号更高的权限。但**不存在形式上的豁免**：一旦Victrl 被定位并销售为 “未授权控制他人电脑” 的工具，“专门设计用于” 这一要件就可能被主张，而一个从社会危害出发而非从 “有无突破” 出发的法院，也可能沿 “AI外挂” 案的路径裁判。

## 四、使用场景风险矩阵

| 场景 | 第285条风险 | 说明 |
| --- | --- | --- |
| 自己的电脑、手机、实验机、家庭实验室 | 无 | 权利在你，缺少 “未经授权” 要件 |
| 企业 UI 自动化 / 测试机群，客户有书面授权 | 无 | 留存授权文件，不超出授权范围 |
| 无障碍辅助、老旧设备或工控 HMI 自动化，设备方同意 | 无 | 同意宜留痕；范围很重要 |
| 同事、家人的设备，确有知情同意 | 低，取决于证据 | 需能证明同意，且不得越权 |
| 公司发给你、但明确不允许自动化的笔记本 | 低至中 | 同意受用人单位制度限制；篡改数据另有第286条风险 |
| 未获授权，在他人机器上无人值守使用 | **是——第285条第2款** | 参见上述门槛；20 台 / 5000 元很容易达到 |
| 用 Victrl 抓取他人账号口令、验证码 | **是——第285条第2款** | 10 组 / 500 组门槛很容易触发 |
| 通过 Victrl 删除、篡改他人数据 | **同时触第286条** | 破坏类罪名；“我有权进入” 不能对抗 “我改了别人的数据” |
| 把 Victrl 作为 “控制/破解他人电脑” 的工具分发、销售 | **是——第285条第3款** | 指向分发行为本身 |

## 五、项目要求每位使用者遵守的规则

1. **只用于已获授权的目标。** 只连接 (a) 你本人拥有或合法占有的设备，或 (b) 已获得设备所有权人/管理人**事前书面授权**的设备。请保留书面授权。
2. **不用于隐蔽。** 不要用 Victrl 隐藏其在目标上的存在或行为，也不要把它伪装成键鼠之外的任何东西。
3. **不用于非法目的。** 不得用于获取他人账号口令、验证码、个人信息，不得用于诈骗，不得用于投放恶意软件。
4. **尊重目标设备的规则。** 遵守目标设备的软件许可协议、用人单位的 IT 制度及相关安全要求。
5. **责任自负。** 使用方式的责任由**操作者**承担，而非项目或维护者。在中国大陆，操作者可能触及《刑法》第285条、第286条及《网络安全法》第27条；为非法用途而分发者，也可能被追究。

## 六、降低风险的工程实践

如果你在 Victrl 之上继续开发，以下设计既能改善产品，也能在将来证明它**不是 “专门设计” 用于非法控制**：

- 任务启动时记录**本次运行的授权人、授权设备、授权范围**，并与任务日志一并留存；
- 让 Victrl 主机的身份与活动**可见**（例如被控侧的状态标识或心跳），而不是刻意隐身；
- 任务日志与设备画像只保存在 **Victrl 主机**，不落在被控设备上；
- 对**破坏性动作**要求每任务显式确认后才执行；
- 不添加以 “破坏、关闭或规避被控设备安全机制” 为目的的功能；
- 不把项目宣传或描述为 “绕过、破解、隐身” 工具。
