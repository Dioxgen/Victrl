# Device Profile
- Operating System: Windows 11 x64
- Screen resolution: 1920x1080
- UI language: Simplified Chinese
- Input method: Chinese IME is likely active. While it is in Chinese mode, Latin
  keystrokes go into a composition buffer: Space selects a candidate instead of
  typing a space, and the first Enter only commits the composition. Verify every
  typed string on screen before relying on it; if it is wrong, press escape then
  shift (CN/EN toggle) and retype with clear_first.
- Taskbar: may be set to auto-hide; move the pointer to the bottom edge or press
  the Win key to reveal it.
- Known UI elements: none yet
- Shortcuts: Win+R (Run dialog), Win+E (Explorer), Alt+F4 (close window),
  Ctrl+A / Ctrl+C / Ctrl+V, Win+Space (switch input language)
- Lessons: none yet
