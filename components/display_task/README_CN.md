# display_task — LCD 状态显示

## 简介

基于 NV3007 SPI LCD 的状态显示任务。横屏模式 428×142 像素。

## 显示布局（归一化坐标）

```
[IP 地址]        [Step: 15]        [IDLE/RUN/PAUSE]
[任务名称.......................................]
[日志行1............................]
[日志行2............................]
[日志行3............................]
```

所有位置使用归一化坐标 `NX(v)` / `NY(v)` 宏，自适应不同分辨率。

## 更新机制

- 2 秒定时刷新
- 支持 `display_task_notify()` 主动通知刷新
- 从 `agent_get_global()` 获取 Agent 状态
- 从 `stm_get_all_formatted()` 获取近期动作日志

## 配色

| 状态 | 颜色 |
|------|------|
| RUNNING | 绿色 |
| PAUSED | 黄色 |
| EMERGENCY | 红色 |
| IDLE/STEP | 白色 |

## 注意事项

- 必须先调用 `NV3007_Init()` 初始化 SPI 和 LCD
- 使用 12pt 字体（每字符 6×12 像素），配合归一化坐标缩放
- SPI 使用 SPI2_HOST，与 SDMMC 不冲突
